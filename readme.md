# Travel Safely

![CI](https://github.com/Julian-rp/travel-safely/actions/workflows/ci.yml/badge.svg)

Este proyecto tiene como objetivo promover viajes seguros mediante una aplicación web que permite gestion de rutas y pasajeros totalmente gratuito

## Tecnologías usadas
- HTML
- CSS
- JavaScript
- GitHub Actions (CI/CD)

## Integración continua
Este proyecto usa GitHub Actions para ejecutar validaciones automáticas al hacer push o pull request a `main` o `develop`.
